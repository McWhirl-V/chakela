# 查课啦 GitHub Pages 网站

本目录包含查课啦官方信息与支持中心的可发布源文件。

建议将 GitHub 仓库从 `mcwhirlv.github.io` 重命名为与账号 `McWhirl-V` 对应的 `mcwhirl-v.github.io`，然后将本目录中的文件发布到仓库 `main` 分支根目录。

预期公开地址：

- 首页：`https://mcwhirl-v.github.io/`
- 技术支持：`https://mcwhirl-v.github.io/support/`
- 隐私政策：`https://mcwhirl-v.github.io/privacy/`
- 隐私选择与数据删除：`https://mcwhirl-v.github.io/privacy-choices/`
- 使用条款：`https://mcwhirl-v.github.io/terms/`

在仓库 Settings → Pages 中选择 Deploy from a branch、`main` 和 `/(root)`。发布完成后，应使用未登录 GitHub 的浏览器逐一确认上述页面可以访问。
